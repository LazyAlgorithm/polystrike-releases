# Polystrike downloads

Polystrike replaces Ringfall with licensed low-poly art, updated character and weapon animations, and a new name. This repository was renamed from ringfall-releases so its existing release history and rollback points remain available.

Install the current Windows or Linux build through [Tessera Hub](https://github.com/LazyAlgorithm/tessera-hub/releases), or download the latest **polystrike-** beta from [Releases](https://github.com/LazyAlgorithm/polystrike-releases/releases).

The game source remains private. Older Ringfall releases are retained as historical rollback builds; Ringfall is no longer listed as a separate game in the Hub.
